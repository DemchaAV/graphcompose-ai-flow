# User Request

Tighten alignment of the summary block under the line-items table.

In product terms, the three summary rows beneath the line-items table
(`Subtotal`, `Tax (8%)`, `TOTAL`) should not drift away from the
`Amount` column when the page width is narrow or when the line-items
table changes shape. The summary block should read as a continuation
of the table's right edge rather than as a loose attachment hanging
off `table.footer(...)`. The textual reference for the visual target
is unchanged from `revision-001`; see
[`../../reference/reference.md`](../../reference/reference.md).
