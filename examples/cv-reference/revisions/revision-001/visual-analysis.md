# Visual Analysis

## Page Structure

The reference is a two-page A4 portrait resume. Page 1 has a centered
identity header followed by a thick mint horizontal divider and a
two-column content grid. Page 2 continues the two-column grid without the
large identity header.

## Visual Tokens

| Token | Value |
|---|---|
| Accent | muted mint, approximately `#8BCFBE` |
| Body text | near black |
| Secondary text | dark gray |
| Background | white |
| Heading style | spaced uppercase text |
| Main font intent | clean geometric sans-serif |

## Page 1 Regions

- Header: large centered `ROSE HARRIS`, smaller mint `GRAPHIC DESIGNER`.
- Divider: thick mint horizontal rule.
- Left sidebar: Contact, Interests, Education.
- Main column: Profile and Experience.

## Page 2 Regions

- Left sidebar: Expertise, Skills, Social.
- Main column: Experience, Awards, References.

## Risks

- Exact font tracking is not exposed as a direct token in the current
  template draft, so spaced uppercase strings approximate letter spacing.
- Contact and social icons need a future Iconify asset pass.
- Multi-page visual-diff requires page-specific reference/output pairs.
