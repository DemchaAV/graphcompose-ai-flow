# Reference Description

## Document

- Type: two-page A4 portrait resume/CV.
- Style: minimalist editorial resume for a graphic designer.
- Palette: black body text, white page, muted mint accent around
  `#8BCFBE`.
- Typography: uppercase headings with wide tracking, compact body copy.
- Layout: two-column grid below a centered name header on page 1.

## Page 1

Header:

- Centered large name: `ROSE HARRIS`.
- Smaller mint subtitle: `GRAPHIC DESIGNER`.
- Thick mint horizontal rule below the header.

Body grid:

- Left column: Contact, Interests, Education.
- Right column: Profile, Experience.
- Section headings are spaced uppercase mint text.
- Item titles are uppercase black labels.
- Body copy is compact and justified-looking in the reference.

## Page 2

Body grid:

- Left column: Expertise, Skills, Social.
- Right column: Experience, Awards, References.
- Expertise has a simple check mark badge above uppercase categories.
- Skills use horizontal rating lines with small vertical markers.
- Social uses circular icons with labels.
- Awards and references use two-column item grids.

## First-Draft Scope

The first revision should:

- reproduce the two-page structure
- preserve the left/right column balance
- use semantic GraphCompose rows, sections, lists, and lines
- avoid raw coordinate drawing as the main layout strategy
- render to `output.pdf` and `output.png`

Known first-draft limitations:

- social/contact icons are placeholders, not Iconify image assets yet
- exact font and letter-spacing parity is approximate
- no pixel diff is possible until multi-page visual-diff orchestration is
  added
