# CV Reference

Two supplied screenshots define a two-page graphic-designer resume
reference.

- `reference-page-1.png` is the cover/profile page.
- `reference-page-2.png` is the continuation page with expertise,
  skills, awards, social links, and references.
- `reference.png` duplicates page 1 for tools that expect a single
  canonical reference image path.

The first implementation revision is intentionally a semantic
GraphCompose draft rather than a pixel-perfect clone. It preserves the
main visual structure and creates a renderable baseline for revision
work.
